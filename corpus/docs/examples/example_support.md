# Support Team Knowledge Base

Tags: support

## Troubleshooting Login Issues

**Internal procedure for support team only**

### Common Causes:
1. Expired session (timeout: 24 hours)
2. Account locked after 5 failed attempts
3. Browser cache/cookie issues
4. VPN/proxy interference

### Resolution Steps:
1. Ask user to clear browser cache and cookies
2. Check if account is locked in admin panel
3. If locked, verify user identity and unlock account
4. Suggest using incognito mode to test
5. If VPN is active, ask user to disable and retry

### Escalation:
If issue persists after basic troubleshooting, escalate to Tier 2 support with:
- User account ID
- Browser and OS version
- Screenshot of error message
- Attempted solutions

## Handling Billing Disputes

**Internal guidelines**

### Before Processing Refund:
1. Verify charge in payment system
2. Check if within refund policy window (30 days)
3. Review account usage logs
4. Check for previous refund requests

### Standard Responses:
- **Within policy**: "I'll process your refund request. You'll see the credit within 5-7 business days."
- **Outside policy**: "Your purchase was made X days ago, which is outside our 30-day refund window. However, I can offer you Y alternative..."

### Escalation Criteria:
- Amount > $500
- User claims service defect
- Legal language used
- Repeated refund requests

Contact support-escalations@example.com for escalation.
